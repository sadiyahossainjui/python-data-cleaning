# Python Data Cleaning Project

## 📌 Project Overview
This project focuses on cleaning messy sales data using Python and pandas.

## 🛠️ Tools Used
- Python
- pandas

## 🧹 Data Cleaning Steps
- Removed duplicate rows
- Standardized city names
- Handled missing values
- Converted date columns
- Created a revenue column
- Exported cleaned data to CSV

## 📁 Project Files
- `messy_sales_data.csv` → Original messy dataset
- `data_cleaning.py` → Python script for cleaning the data
- `cleaned_sales_data.csv` → Cleaned dataset

## 🔍 Key Insights
- Duplicate records were removed
- City names were standardized
- Missing values were handled
- Revenue was calculated for each order

## 🚀 Skills Demonstrated
- Python programming
- pandas data cleaning
- Missing value handling
- Duplicate removal
- CSV file processing

## 📈 Conclusion
This project demonstrates how Python can be used to clean raw data and prepare it for analysis.
